# 📚 AIUB Library Management System

> A simple **Java Swing** desktop application for managing library books.

---

## ✨ Features

✔️ Add Book  
✔️ View Books  
✔️ Search Book  
✔️ Update Book  
✔️ Remove Book  
✔️ Save & Load Data  

---

## 🛠️ Technologies Used

- Java  
- Java Swing  
- OOP Concepts  
- File Handling
